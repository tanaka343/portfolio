# 業務自動化スクレイピングアプリ
webサイトから情報を収集してエクセルに転記する作業の自動化アプリです。CUI作成後、Flaskを使ったGUIも作成しました。\

## 目的
初めてのアプリ作成でプログラミング基本概念、例外処理やエラーハンドリングの理解を目的に作成しました。\
就労移行支援事業書の事務作業の内容を自動化し、業務の手順書に沿ったスクレイピングプログラムを作成しました。\

## ブランチ構成

- **main**: 本番用（フルバージョン）
- **release**: デモアプリ用（ヘッドレスモード、スクレイピング量削減版）

## 機能
- 操作をguiとcuiの両方で実装
- ブラウザの自動操作（Seleniumを使用）
- 取得したデータを自動でExcelファイルに保存（openpyxl,pandasを使用）
- javaScriptでしか反応しなボタンにも対応
- ページが完全に切り替わるまで待機して処理を実行
- [GUI]Flask.sessionを使ったデータ管理を実装
- pytestを使用した単体テスト作成

## 使い方

- このツールは「〇〇県〇〇市」など地域名を入力することで、Webサイトからその地域内の放課後デイサービスの情報を自動でスクレイピングします。
- 取得する情報は「法人名」、「事業所名」、「Eメール」、「電話番号」、「ホームページURL」を自動でスクレイピングします。
- CUIでは、ユーザーがパス指定したExcelファイルのテンプレートをもとに、データを自動で整形、転記します。
- GUIでは、csv,xlsx形式でファイルをダウンロードできます。

### CUI
1.地域とエクセルファイルパスの入力
```bash
地域を入力 （例：東京都豊島区）東京都豊島区
excelファイルパスを入力"C:\Users\Guest User\OneDrive\デスクトップ\ファイル名.xlsx"
```

※指定Excelファイルのファイルパスをコピーしてそのまま貼り付け\
※指定Excelファイルは業務手順書に準拠\
※指定Excelファイルがない場合は自分でExcelテンプレートを作成し、シート名を「テンプレート※コピーして名前を都市名に変更して使用」に変更してください。（コード内で指定ファイルのテンプレートをコピーして使用しているため）
    
2.出力結果の確認
- ユーザーが入力した市区町村名をシート名にしたExcelsheetが作成され、
スクレイピングした各施設情報（法人名、事業所名、メール、電話、ホームページURL）が転記されます。
- データは行１、列Ａから書き込まれます。

### スクレイピングプログラム部分


- 長時間稼働させてもエラーが起きない工夫\
処理するデータが多くなると、Seleniumの動作が不安定になるため、定期的にブラウザを自動的に再起動するようにしました。

- Webページの構造が特殊な場合にも対応\
地域選択をする場面で通常、「都道府県 → 市町村」と進みますが、政令指定都市などは、「都道府県 → 区」になるケースがあります。\
このような構造の違いも例外処理を加えて自動で対応できるようにしました。

- SeleniumとJavaScriptを適切に使い分け\
通常のブラウザ操作はSeleniumで、スクロールやJavaScriptでしか反応しないボタンはJavaScriptで直接操作しました。

### GUI

- データ管理戦略\
検索結果の一時保存には、以下の理由からセッション（Flaskのsession）を採用しました。\
同じ地域を連続して検索した場合、セッションに保存した前回の検索結果を再利用します。これにより不要なスクレイピングを防ぎ、レスポンス速度を向上させています。\
**実装の判断基準：**
    - 検索結果は一時的なデータ（ユーザーごと、セッションごとに異なる）
    - データサイズは数百KB程度（DataFrame → JSON）
    - 永続化の必要なし（ブラウザを閉じたら破棄してOK）\
    → データベースやファイルシステムではなく、セッションストレージを採用
